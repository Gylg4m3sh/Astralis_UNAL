# Astralis_UNAL

## Introducción:
ASTRALIS es una plataforma que tiene el propósito de simular, visualizar y predecir fenómenos astronómicos utilizando datos reales de la NASA. Siendo una aplicación en donde no solo se va a limitar en el ámbito académico , sino también tendrá aspectos reales como lo son: La seguridad, automatización y uso de modelos de machine learning.

## Roles:
E1- Backend(Cristian Moreno):

Será el encargado de diseñar y desarrollar la API que servirá como núcleo del sistema para la comunicación entre todos los módulos. Se encarga de gestionar la lógica, la autenticación y la seguridad de datos, Para esto , utilizará herramientas como FastAPI,PostgreSQL,JWT,OAuth2 y OpenAPI.
E2-DevOps(Stephan Garcia):

El DevOps Engineer será responsable de la automatización y despliegue del sistema, asegurando que todo el código desarrollado por el equipo llegue de manera continua y confiable a producción. Su trabajo incluye la configuración del pipeline CI/CD, la contenerización del sistema y el monitoreo de su funcionamiento. Para esto, emplea herramientas como GitHub Actions, Docker, Railway y Grafana Cloud, permitiendo mantener la estabilidad y disponibilidad del sistema en todo momento
E3-Machine learning(Santiago Zamora Garzon):

El ML & Physics Engineer tendrá la responsabilidad de desarrollar el componente científico del sistema, incluyendo el entrenamiento del modelo de Machine Learning para clasificar exoplanetas y la construcción del simulador físico de cuerpos celestes. Este rol implica trabajar con datos reales y generar predicciones precisas. Para lograrlo, utilizará herramientas como Python, scikit-learn, rebound, Jupyter Notebooks y APIs de la NASA, integrando estos resultados con el resto del sistema. 
E4 -Frontend(Daniel Garzon):

El Frontend Engineer será el encargado de diseñar e implementar la interfaz de usuario, transformando los datos complejos en visualizaciones interactivas y comprensibles para el usuario final. Su objetivo es crear una experiencia atractiva y funcional que permita explorar simulaciones y datos astronómicos. Para ello, utilizará tecnologías como React.js, Three.js, Canvas API y Vite, logrando una interfaz dinámica y visualmente impactante.
